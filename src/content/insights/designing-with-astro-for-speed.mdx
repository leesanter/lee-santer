## The tension: pace vs polish

Most ‘fast’ sites look empty because we cut the wrong things. The trick is ruthlessly trimming **what the browser has to do first**, not the design itself…

- Inline only critical CSS, defer the rest.
- Prefer native elements; sprinkle interactivity, don’t drown in it.
- Optimise image aspect ratios up-front; stop relying on layout shifts.

Wrap it all in a component discipline so the choices stick.
